# 관계장부 (relation-ledger)

RisuAI 플러그인입니다. 긴 대화에서 **누가 누구와 어떤 사이인지, 지금 어떤 상태인지**를 따로 적어 두고, 보낼 때마다 그 장면에 필요한 것만 골라 프롬프트에 싣습니다.

대화가 길어지면 앞쪽이 잘려 나가고, 로어북은 켜 두면 전부 실려 토큰을 잡아먹습니다. 관계장부는 그 사이를 메우려고 만들었습니다.

## 무엇을 하나

- **기억 기록** — 답이 끝나면 그 턴에서 확인된 것(관계·상태·외모·소지품 같은 것)을 장부에 적습니다.
- **감독** — 보낼 때, 이번 장면에 필요한 기억만 골라 싣습니다. 장부 전체를 싣지 않습니다.
- **그림 태그** — 인물마다 그림 태그를 관리해 삽화를 만들 때 함께 넘깁니다. 옷을 갈아입거나 벗은 상태도 따라갑니다.
- **화면** — 대화 안의 버튼으로 기억을 보고, 고치고, 틀린 것을 고정해 둘 수 있습니다.

## 무엇이 달라지나

한 대화(로어북이 크고 인물이 많은 무협 카드)에서 잰 값입니다. 환경이 다르면 결과도 다릅니다.

| | 전 | 후 |
|---|---:|---:|
| 10턴 전 일을 물었을 때 제대로 답한 횟수 | 3/11 | 10/11 |
| 감독에게 가는 입력 | 약 120,000토큰 | 약 23,000토큰 |
| 로어북에서 실리는 양 | 169,065자 | 80,191자 |
| 프롬프트에 실린 「확인된 현재 상태」 | 0개 | 15~25개 |

## 설치

1. `relation-ledger.js` 를 받습니다. (내려받은 파일이 맞는지 확인하려면 SHA256 이 `879a9ac2391e6213321140b7f6a4595146e12ea2f7e1cfb5e5c5e14e5bcefcf2` 입니다.)
2. RisuAI 설정 → 플러그인 → 가져오기로 그 파일을 넣습니다.
3. 처음 켤 때 묻는 권한을 허용합니다(대화 내용을 읽고 쓰는 권한이 필요합니다).
4. 플러그인 설정에서 **기억 AI·감독 AI**에 쓸 모델과 열쇠를 적습니다.

## 쓰기 전에 알아 둘 것

- **AI 호출이 늘어납니다.** 한 턴에 본문 말고도 감독과 기억 기록이 따로 돌아갑니다. 요금이 그만큼 더 나갑니다. 값싼 모델을 따로 지정할 수 있습니다.
- **아직 시험판입니다.** 쓰다 보면 손볼 곳이 나옵니다.
- **그림체는 비어 있습니다.** 그림체 이름과 프롬프트·제외 태그는 설정에서 직접 넣어 주세요. 쓰시던 것이 있으면 그대로 붙여 넣으면 됩니다. (장면을 그림 태그로 옮기는 지침은 들어 있습니다.)
- 자료는 RisuAI 안에 저장됩니다(플러그인 저장소). 기기를 옮길 때는 「키 저장 방식」을 공유로 두어야 같이 따라갑니다.

## 초벌이란

인물이 수십·수백 명인 카드에서는, 대화를 시작하기도 전에 이미 등장인물이 정해져 있습니다. 이때 로어북을 한 번 훑어 **인물 명부를 미리 만들어 두는 것**을 초벌이라고 부릅니다. 초벌이 있으면 첫 턴부터 이름·별호·한자 표기를 알아보고, 같은 사람을 다른 이름으로 또 만들지 않습니다.

초벌은 로어북 항목 하나에 이런 모양으로 들어갑니다.

```
<!-- relation-ledger:seed:v1 -->
{"format":"relation-ledger.lore-seed","version":1,
 "entities":[
   {"id":"lore:가람","name":"가람","aliases":["Garam","伽藍","푸른 손"],"type":"person"},
   {"id":"lore:나린","name":"나린","aliases":["Narin","那潾"],"type":"person"},
   {"id":"lore:은방울 역참","name":"은방울 역참","aliases":["Silver Bell Station"],"type":"place"}
 ]}
```

그림 태그를 같이 넣을 때는 항목을 하나 더 두고 인물별로 적습니다. 앞의 숫자는 가중치입니다.

```
### 가람
4::tall woman, long black hair::, 3::blue robe, silver bracelet::, 2::scar on cheek::, female focus
```

**초벌 파일 자체는 여기에 올리지 않습니다.** 초벌은 그 카드의 설정집을 바탕으로 만들어지기 때문에, 내용이 카드 제작자의 것입니다. 쓰시는 카드로 직접 만들어 주세요.
